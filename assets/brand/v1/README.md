# Dogstar brand package v1

- `dogstar-logo-on-navy.svg`, `dogstar-logo-on-light.svg`: the Dogstar Technologies logo for dark and light backgrounds (vector masters).
- `dogstar-star.svg`: the guiding star alone. `favicon.svg`: the star on navy, for browser tabs and app icons.
- `constellation-by-dogstar-on-navy.svg`, `constellation-by-dogstar-on-light.svg`: the Constellation by Dogstar lockup (text outlined, no font needed).
- `tokens.css`, `tokens.json`: colour, type, size and spacing tokens, the same values as the public site.
- `MANIFEST.json`: version, date, and bytes and sha256 of every file above.

v1 never changes in place. A new version is a new folder (v2), announced to the Platform lane.
